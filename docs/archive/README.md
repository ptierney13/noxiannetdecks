# Archive

This folder contains completed or superseded historical documentation.

## What Belongs Here

- completed work moved out of `docs/work/`
- superseded initiative docs and stage folders
- older historical documents kept for rationale, context, or change history

## How To Use Archive Docs

Archive docs may be read for:

- historical context
- rationale behind past decisions
- understanding how the project evolved

Archive docs should not be treated as:

- the current source of truth
- active requirements
- current implementation constraints unless a live doc explicitly re-adopts
  them

## Move Rules

- completed active work moves from `docs/work/` into `docs/archive/work/`
- only historical material belongs here
- evergreen rules should stay in `README.md`, `AGENTS.md`, reference docs, or
  runbooks instead of being buried in the archive
