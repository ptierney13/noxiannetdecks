# Repo-Local Agents

This folder holds repo-local agent extensions.

- `openai.yaml` defines the repo-local Codex agent surface and default prompt.
- `skills/` contains repo-local Codex skills and recurring maintenance
  workflows.

Claude and other agents should also read the files here, but the canonical format
should be the Codex skill format documented in
[skills/README.md](./skills/README.md).
